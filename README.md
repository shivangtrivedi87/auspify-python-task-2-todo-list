# To-Do List Application

A simple command-line To-Do List application built with Python as part of the Auspify Technologies Python Development Internship.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks to a JSON file
- Load saved tasks when the application starts
- Reuse available task IDs after deletion
- Validate user input
- Menu-driven command-line interface

## Technologies Used

- Python 3.14+
- JSON
- Lists and Dictionaries
- File Handling
